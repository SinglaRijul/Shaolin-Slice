# Shaolin-Slice
Shaolin slice is a rhythm game set in medieval China, through this game you play as a Shaolin monk. Throughout this game you must slice your way to overcome every challenge, from slicing bamboo for pandas to slicing your enemies on the battlefield.

This game intends to use lots of historical reference with its themes and lots of accuracy with each movement the monk performs, from stances to slices, and even parts of the music.

Use the arrow keys to slice in time to the beat
